# Projet tp4-debug

API « boutique » — Java 21, Spring Boot 4.2, Maven.
Code : `src/main/java/fr/formation/boutique/`. Tests : `src/test/java/fr/formation/boutique/` (MockMvc).

## Commandes
- Compiler : `mvn -B -ntp compile`
- Tests : `mvn -B -ntp test`
- Lancer : `mvn -q spring-boot:run` (port 8080)
- Logs applicatifs : `logs/app.log`
